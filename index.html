Install from the Terminal

Short, typeable URLs for tools published from phantomlives-releases. Paste these into Terminal — they are commands, not download links.

/pmon — PurpleMonitor

curl -fsSL https://bronty13.github.io/pmon | bash

Installs to /Applications and launches. It reads the app's own release feed, so it always installs the current version, then refuses to install unless the download passes strict code-signature verification, carries a valid Apple notarization ticket, is accepted by Gatekeeper, and is signed by the expected Apple Developer Team. No sudo, and it never disables Gatekeeper. Prefer clicking? Use the download page instead.

/bau — brew-autoupdate

curl -fsSL https://bronty13.github.io/bau | bash

Scheduled Homebrew updates on macOS, with logs and a brew-logs viewer. This serves the same bootstrap.sh published to the release feed; it verifies its download against a SHA-256 checksum before installing anything.
