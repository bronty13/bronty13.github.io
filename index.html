Install scripts

Short, typeable URLs for tools published from phantomlives-releases.

/bau — brew-autoupdate

Scheduled Homebrew updates on macOS, with logs and a brew-logs viewer.

curl -fsSL https://bronty13.github.io/bau | bash

This serves the same bootstrap.sh published to the release feed; it verifies its download against a SHA-256 checksum before installing anything.

/pmon — PurpleMonitor

A Mac X-ray: scans macOS for security and health problems, explains every artifact in plain English, and shows what changed since a known-good baseline. Needs macOS 14+.

curl -fsSL https://bronty13.github.io/pmon | bash

Installs to /Applications. It reads the app's own Sparkle release feed, so it always installs the current version, then refuses to install unless the download passes strict code-signature verification, carries a valid Apple notarization ticket, is accepted by Gatekeeper, and is signed by the expected Apple Developer Team. No sudo, and it never disables Gatekeeper.

After installing, grant it Full Disk Access (System Settings → Privacy & Security → Full Disk Access) or most of the scan can’t run. Add -s -- --to "$HOME/Applications" to install for one user only.
