Install it

  1. Click Download above.
  2. If it doesn't unzip by itself, double-click the downloaded file — you'll get PurpleMonitor.app.
  3. Drag PurpleMonitor.app into your Applications folder.
  4. Open it from Applications.
One more step, and it matters. Grant PurpleMonitor Full Disk Access: System Settings → Privacy & Security → Full Disk Access, then switch PurpleMonitor on and reopen it. Without it the most useful checks can't run — they're reported honestly as coverage gaps rather than as “nothing found,” but you'll be missing results.

Requires macOS 14 (Sonoma) or later on an Apple Silicon Mac. The app is signed with an Apple Developer ID and notarized by Apple, so it opens without security warnings. It keeps itself up to date after that.

Prefer the Terminal?

One line, and it does everything above — including verifying the download before it installs anything:

curl -fsSL https://bronty13.github.io/pmon | bash

It refuses to install unless the download passes code-signature verification, carries a valid Apple notarization ticket, is accepted by Gatekeeper, and is signed by the expected developer. It never asks for your password.
